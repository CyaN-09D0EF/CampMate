# ⛺ CampMate · 캠프메이트

**캠핑장 탐색과 캠핑용품 거래를 하나의 서비스로 연결하는 졸업작품 웹 프로젝트입니다.**

구현 코드는 브랜치별로 다릅니다. `master`는 초기 골격이며, `test1`·`test2`·`test3`에는 캠핑장 탐색, 용품 거래, 커뮤니티, 고객센터 등 확장 구현이 있습니다.

[실행 가이드](docs/SETUP.md) · [시스템 구조](docs/ARCHITECTURE.md) · [발표 및 개발 체크리스트](docs/PROJECT_STATUS.md)

## 프로젝트 소개

캠핑을 준비할 때 필요한 장소 탐색과 장비 탐색을 한 화면에서 시작할 수 있는 서비스를 목표로 합니다. 메인 화면은 캠핑 이미지 슬라이드, 키워드 입력, 태그 선택, 추천 장비 카드로 구성했습니다.

> 아래 표는 `master`와 개발 브랜치를 구분한 코드 확인 결과입니다. 개발 브랜치의 전체 기능을 실행 검증한 것은 아닙니다.

## 주요 기능

회원가입·로그인 등 아래 기본 기능 설명은 `master` 기준입니다. 개발 브랜치의 차이는 [브랜치 현황](docs/PROJECT_STATUS.md#브랜치별-구현-현황)을 참고하세요.

| 기능 | 현재 구현 범위 |
| --- | --- |
| 메인 화면 | 캠핑 이미지 슬라이드, 태그 선택 UI, 상품 카드 표시 |
| 상품 조회 | DB에서 상품명·가격·이미지를 조회하여 JSON으로 응답 |
| 회원가입 | 아이디 중복 조회, BCrypt 비밀번호 해시 저장 |
| 로그인·로그아웃 | 비밀번호 검증, 세션 저장 및 해제 |
| 이메일 인증 | 코드 저장·만료 확인·검증 API 구현, 실제 메일 발송은 SMTP 설정 필요 |
| 캠핑장 탐색 | `master`: 검색 UI / 개발 브랜치: `CampListServlet`, 목록·상세 화면 구현 |
| 용품 거래 | 개발 브랜치에 목록·상세·등록 화면, `test3`에 수정·삭제·채팅 처리 코드 구현 |
| 커뮤니티 | 개발 브랜치에 커뮤니티 화면, 후기·소식·이벤트 페이지 구현 |
| 고객센터 | 개발 브랜치에 고객센터 화면, 문의 등록·상세·답변 처리 코드 구현 |

## 저장소 구조

```text
CampMate/
├── README.md
├── docs/                         # 실행·설계·진행 현황 문서
└── camp/                         # Eclipse 웹 프로젝트
    └── src/main/
        ├── java/
        │   ├── controller/       # 상품·중복 확인·메일 인증 Servlet
        │   ├── dao/              # 사용자·상품 DB 접근
        │   ├── dto/              # 상품 데이터 객체
        │   └── util/             # DB 연결·메일·비밀번호 처리
        └── webapp/
            ├── assets/img/       # 캠핑 및 상품 이미지
            ├── WEB-INF/lib/      # 프로젝트에 포함된 라이브러리
            ├── sql/init.sql      # 테이블 및 샘플 데이터
            └── *.jsp             # 메인·회원가입·로그인 화면과 처리
```

## 실행하기

아래 실행 가이드와 시연 흐름은 `master`의 초기 버전 기준입니다. 개발 브랜치는 DB 스키마·의존성·설정이 달라 별도 확인이 필요합니다.

JDK 21, Tomcat 10.1, MySQL 호환 DB를 준비한 뒤 Eclipse에서 `camp/`를 기존 프로젝트로 가져옵니다. DB를 초기화하고 Tomcat에 배포하면 `/camp/index.jsp`에서 시작할 수 있습니다.

DB 생성 명령, 서버 설정과 확인 절차는 **[실행 가이드](docs/SETUP.md)**를 참고하세요. Maven·Gradle 빌드 파일과 자동화 테스트는 아직 없습니다.

## 시연 흐름

1. 메인 화면에서 캠핑 이미지와 상품 카드 4개를 확인합니다.
2. 회원가입 화면에서 기존 아이디와 새 아이디의 중복 확인 결과를 비교합니다.
3. SMTP가 준비된 경우 이메일 인증과 회원가입을 진행합니다.
4. 가입한 계정으로 로그인하고 이름 표시 및 로그아웃을 확인합니다.

초기 SQL의 `test` 계정은 평문 비밀번호로 저장되어 현재 BCrypt 로그인에 사용할 수 없습니다. 시연 전 [점검 항목](docs/PROJECT_STATUS.md)을 확인하세요.
